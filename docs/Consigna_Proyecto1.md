## Proyecto 1: Estimación de Constantes Matemáticas (π y e)

El Método de Monte Carlo es una técnica numérica que utiliza el muestreo aleatorio masivo para resolver problemas deterministas. En este proyecto se explorará la estimación de dos constantes fundamentales. Investigue utilizar estos métodos para obtener una aproximación de π y e. Pruebe hacer diferentes números de simulaciones. Investigue la convergencia y el error a medida que aumenta el número de simulaciones.
